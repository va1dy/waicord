# Waicord

Дискорд-бот с современной веб-панелью (UI). Пока в разработке: архитектура и заготовки.

## Стек

- **Bot** — TypeScript + discord.js (`apps/bot`)
- **Web UI** — Next.js + React (`apps/web`)
- Node.js >= 20, pnpm workspaces

## Установка

```bash
pnpm install
cp .env.example .env   # вставь токен бота
pnpm dev               # запуск бота и веба
```

## Структура

```
waicord/
├── apps/
│   ├── bot/      # Discord-бот: команды, события
│   └── web/      # Веб-панель (Next.js)
├── docs/         # Архитектура, решения
├── AGENTS.md     # Правила совместной работы (читать обязательно)
└── README.md
```

## Совместная работа

Правила для двух разработчиков и ИИ-ассистентов — в [AGENTS.md](./AGENTS.md).
Коротко: каждый работает в своей папке, `main` защищён, общие файлы — только через PR с одобрением обоих.
