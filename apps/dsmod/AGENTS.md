# AGENTS.md

> TL;DR: работаем по веткам, коммиты — Conventional Commits, `main` не трогаем напрямую,
> секреты только в `.env`, перед «готово» — `bun run typecheck`.

Правила для людей и ИИ-агентов. **Читать перед каждой сессией.**

## 0. Статус проекта

- Стек: **Bun + TypeScript** (строгий `tsconfig`), рантайм-зависимостей почти нет.
- Голос/звонки (2026-10): добавлены рантайм-зависимости `opusscript` (кодек Opus, MIT),
  `@noble/ciphers` (XChaCha20-Poly1305 для транспортного AEAD, MIT),
  `@snazzah/davey` (E2EE DAVE через NAPI, MIT — та же библиотека, что в `@discordjs/voice`).
  Код — `src/voice/**`, контракт — `docs/voice.md`.
- Архитектура зафиксирована: SDK (`src/`) + локальный HTTP-мост (`src/server/`) + UI поверх него.
- Новый фреймворк/зависимость — обсуждаем вдвоём и пишем в этот файл.

## 2. Git

- Ветки: `main` защищена (нет прямых коммитов, нет force-push, нет `reset --hard`);
  фичи — `feature/<имя>/<короткое-имя>`.
- Commits: Conventional Commits — `feat: …`, `fix: …`, `docs: …`, `chore: …`.
  Тело коммита объясняет **что и зачем**, одной строкой.
- Мелкие коммиты: одно логическое изменение = один коммит.
- Перед работой: `git fetch && git rebase origin/main` (когда появится remote).

## 3. Что обязаны делать ИИ

1. Работать в своей зоне; общее → вопрос человеку.
2. Не придумывать архитектуру за нас: контракт API менять только по согласованию.
3. Перед «готово» — прогнать проверки и починить ошибки:
   ```bash
   bun run typecheck          # обязателен
   bun start & bun run scripts/smoke.ts   # если менялся мост
   ```
4. Минимальные diff'ы: без рефакторов и форматирования «по пути».
5. Никогда: force-push, секреты в коде, токены в логи и в UI, коммиты от имени человека.
6. Стиль = как в соседнем коде; комментарии только для неочевидного; документация на русском.
7. Если меняешь `src/types.ts` — обнови `docs/api.md` и `docs/ui.md` в том же коммите.

## 4. Безопасность (не обсуждается)

- Токен хранится только в `~/.dsmod/session.json` или в `.env` (оба в `.gitignore`).
- Мост слушает **только** `127.0.0.1`.
- В логи не пишем токены, пароли, содержимое `Authorization`.
- `.env` и `session.json` не попадают в коммиты — проверяй `git status` перед `git add`.
